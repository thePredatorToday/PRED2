# 🦅 THE PREDATOR - Solana Trading Bot

**Verze:** 1.3 | **Stav:** Production-Ready (Fáze 1-3 Hotovo)

Automatizovaný tradingový bot pro Solanu zaměřený na asymetrické příležitosti v memecoinech. 

## 🎯 Quick Start

### Instalace

```bash
python -m venv venv
source venv/bin/activate  # Linux/macOS
pip install -r requirements.txt
cp .env.example .env
# Edituj .env se svými klíči
```

### Spuštění

```bash
python main.py
```

Nebo dashboard:
```bash
streamlit run scripts/dashboard.py
```

## 📊 Testy

```bash
pytest tests/ -v
```
